# Git Branch Visualizer

A React application to visualize Git branch strategies with a SpaceX-inspired design.

## Project Setup

This project was set up using Vite.

```bash
npm create vite@latest git-branch-visualizer --template react
cd git-branch-visualizer
npm install
```

## Features

*   Visualize commit history and branch relationships.
*   Dark, futuristic UI inspired by SpaceX.
*   Basic canvas-based graph rendering (further development needed for complex layouts).
*   Support for sample Git data input.

## Technologies

*   React
*   Vite
*   React Router DOM
*   Tailwind CSS
*   Custom CSS for theming

## Getting Started

1.  **Clone the repository (if not already cloned):**
    ```bash
    git clone https://github.com/vitas-brc20/agent-test.git
    cd agent-test
    # Assuming you will create this project within this repo
    # If creating a new repo, follow the above 'Project Setup' steps
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173` (default Vite port).
